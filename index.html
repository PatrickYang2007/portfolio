Hybrid search over genomics literature

Hybrid retrieval over 19,791 genomics abstracts, fusing full-text and pgvector embedding search with reciprocal rank fusion — 0.82 Recall@50 and 0.85 nDCG@10 on a graded-relevance harness. A fine-tuned cross-encoder reranker adds +41% MRR over off-the-shelf.

Python · PostgreSQL · PyTorch · FastAPI

remapd

Congressional redistricting engine — Claude Hackathon finalist (~50 teams)

Scores congressional maps for all 50 states on population balance, compactness, and voting-rights proxies. A simulated-annealing optimizer improves the median objective +27% over random baselines, running 700 iterations on 254 counties in under a second.

Python · LangGraph · Claude API · FastAPI · Next.js

Heterogeneity Score

Chromatin variability from DNA sequence

Deep learning pipeline predicting chromatin heterogeneity from DNA alone: 5.6M regions as 2048 bp windows into an attention-pooled CNN. Also diagnosed why the task resists learning — 41% of labels saturate at the score's ceiling, and predictive signal plateaus at 256 bp.

PyTorch · SLURM · Genomics
