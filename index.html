01Selected work
  1. 01

    regsearch

    Hybrid search over genomics literature

    RAG-style hybrid retrieval over 19,791 genomics abstracts (99,567 passages), fusing SQL full-text search and pgvector embedding search with reciprocal rank fusion behind a FastAPI REST API. A graded-relevance eval harness — 704 pooled candidates across 40 queries, LLM-as-judge with hand adjudication — shows hybrid beats either mode alone: 0.82 Recall@50, 0.85 nDCG@10. A cross-encoder reranker fine-tuned on citation-derived labels adds +41% MRR over off-the-shelf.

    Python · PostgreSQL · PyTorch · FastAPI

  2. 02

    remapd

    Congressional redistricting engine — Claude Hackathon finalist (~50 teams)

    Scores congressional maps for all 50 states on population balance, compactness, and voting-rights proxies. A simulated-annealing optimizer over county-to-district assignments in NumPy improves the median objective +27% over random baselines, running 700 iterations on 254 counties in under a second. A 5-node LangGraph pipeline with Claude tool use turns metric vectors into streamed analytical memos grounded in US Census API calls.

    Python · LangGraph · Claude API · FastAPI · Next.js

  3. 03

    Heterogeneity Score

    Chromatin variability from DNA sequence

    End-to-end deep learning pipeline predicting chromatin heterogeneity (0–1) from DNA alone: 5.6M regions as 2048 bp one-hot windows, whole-chromosome train/val/test splits, and an attention-pooled CNN. Also diagnosed why the task resists learning — 41% of labels saturate at the score's ceiling, an artifact intrinsic to the label definition, and context-crop sweeps show predictive signal plateaus at 256 bp.

    PyTorch · SLURM · Genomics
